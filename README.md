概述
trading_strategy_backtest.py 是一個基於 Python 的簡單移動平均線 (SMA) 交叉策略回測程式，專為金融市場數據分析設計。該程式使用 Yahoo Finance 的歷史價格數據，實現了 SMA 交叉交易策略的回測，並計算關鍵績效指標（如總回報、年化回報和夏普比率），同時生成可視化結果。

功能
數據下載：透過 yfinance 從 Yahoo Finance 下載指定標的（如 AAPL）的歷史價格數據。
SMA 交叉策略：計算短期和長期移動平均線（預設為 20 天和 50 天），生成買入（短期 SMA 上穿長期 SMA）和賣出（短期 SMA 下穿長期 SMA）信號。
回測邏輯：計算策略的日回報、累積回報、年化回報和夏普比率（假設無風險利率為 0）。
可視化：生成累積回報圖表，對比「買入並持有」與策略表現，並標記買賣信號，支援中文顯示（使用微軟雅黑字體）。
輸出：將結果圖表儲存為 backtest_result.png，並在終端機顯示回測績效。
環境需求
Python 3.6+
必要套件：
pip install yfinance pandas numpy matplotlib
支援中文的字體（如微軟雅黑，Windows 預設安裝）。
使用方式
將程式碼儲存為 trading_strategy_backtest.py。
在命令提示字元 (CMD) 或終端機中，導航至檔案所在資料夾：
cd 你的檔案路徑
執行程式：
python trading_strategy_backtest.py
程式將下載 AAPL 的歷史數據（2020-01-01 至 2025-04-30），執行回測，並生成 backtest_result.png。
修改建議
標的變更：修改 main() 中的 ticker 變數（例如，改為 BTC-USD 測試比特幣）。
參數調整：調整 short_window 和 long_window 以優化策略。
交易成本：當前未考慮交易手續費，可在 backtest() 函數中加入手續費邏輯。
時間範圍：修改 start 和 end 日期以測試不同時期。
注意事項
確保網路連線正常以從 Yahoo Finance 下載數據。
比特幣等加密貨幣市場為 24/7 交易，夏普比率計算需將 252（股票交易日）改為 365（全年交易日）。
中文顯示需系統支援指定字體，若圖表亂碼，可將字體改為 SimHei 或其他支援中文的字體。
範例輸出
執行後，終端機可能顯示：

總回報: 45.67%
年化回報: 12.34%
夏普比率: 0.89
並生成包含累積回報曲線和買賣信號的圖表。
